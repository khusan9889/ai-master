# AI Master

Лендинг платформы обучения ИИ для проверки спроса: заявки в Telegram и собственная аналитика в админ-панели.
Регистрации и оплаты на этом этапе нет — все кнопки покупки ведут на заявку.

## Что внутри

```
server/
  index.js      — сервер Express: API сайта и админки, раздача статики
  analytics.js  — приём событий и отчёты (визиты, клики, воронка, источники, UTM)
  telegram.js   — отправка заявок в Telegram-группу
  db.js         — хранилище (JSON-файл с атомарной записью)
  seed.js       — начальные курсы, уроки и тарифы
public/
  index.html    — сайт
  admin.html    — админ-панель (/admin)
data/           — база и события (создаётся при запуске, в git не попадает)
```

### Сайт
Главная, каталог, страница курса, пробные уроки (квизы, песочница, ИИ-наставник), страница для компаний.
Кнопки «Оформить подписку», «Купить курс», «Оставить заявку» открывают форму — заявка уходит в Telegram-группу
вместе с источником трафика (UTM-метки, Facebook/Instagram/Google).

### Админ-панель (`/admin`)
- **Аналитика** — посетители, визиты, просмотры, заявки, конверсия, время на сайте; клики по «Оформить подписку»
  и «Купить курс» (по тарифам/курсам и местам на сайте); график по дням; воронка; источники трафика; рекламные
  кампании по UTM; популярные страницы; устройства, браузеры, системы; онлайн сейчас.
- **Заявки** — статусы, заметки, источник, повторная отправка в Telegram, выгрузка в CSV.
- **Курсы** — тексты, цены, программа, пробные уроки, редактор контента.
- **Тарифы**, **Настройки** (Telegram, пиксели Meta / Яндекс Метрика / GA4, контакты).

### Ссылки для рекламы

`https://ваш-сайт/?utm_source=instagram&utm_medium=cpc&utm_campaign=test1&utm_content=video_a`

## Запуск

Нужен Node.js 18.17+.

```bash
npm install
cp .env.example .env   # пароль админки, токен бота, ID группы
npm start              # http://localhost:3000, админка — /admin
```

`.env` содержит секреты — не коммитьте его.

## Хостинг
Любой VPS с Node.js: `npm ci --omit=dev && npm start` под pm2 или systemd, перед ним nginx с HTTPS.
Папку `data/` нужно сохранять при обновлениях и бэкапить.
