# AI Master

Платформа практического обучения ИИ: сайт, REST API, админ-панель, заявки в Telegram.

## Что внутри

```
server/
  index.js      — сервер Express: API сайта и админки, раздача статики
  db.js         — хранилище (JSON-файл с атомарной записью, без нативных зависимостей)
  telegram.js   — отправка заявок и уведомлений в Telegram-группу
  seed.js       — начальные курсы, уроки, тарифы и промокоды
public/
  index.html    — сайт (SPA без сборки)
  admin.html    — админ-панель (/admin)
data/db.json    — база данных (создаётся при первом запуске, в git не попадает)
```

### Сайт
- Главная с понятным маршрутом: «С чего начать?» (новичкам / для работы / для бизнеса / разработчикам), подбор курса за 4 вопроса, цены, FAQ и форма консультации.
- Каталог с поиском и фильтрами-чипами, страница курса, плеер урока (теория, квизы, песочница, ИИ-наставник).
- Вход по телефону (SMS — **демо**, код задаётся в админке), онбординг, личный кабинет, сертификаты с проверкой по номеру.
- Оформление заказа с промокодами, оплата — **демо** (Click / Payme подключаются позже).
- Доступ к платным урокам проверяется на сервере.

### Заявки → Telegram
Формы «Заказать звонок», «Вопрос по курсу», «Подбор курса» и «Обучение для команды» сохраняют заявку в базе
и отправляют её в Telegram-группу. Если группа станет супергруппой, новый ID подхватится автоматически.
Защита от спама: скрытое поле-ловушка и лимит запросов по IP.

### Админ-панель (`/admin`)
- Дашборд: заявки, пользователи, выручка, график за 14 дней.
- Заявки: статусы (новая / в работе / успешно / отказ), заметки менеджера, повторная отправка в Telegram, выгрузка в CSV.
- Пользователи: выдать/забрать курс, выдать подписку.
- Заказы: история, возвраты.
- Курсы: цены, описание, публикация, программа, редактор контента уроков.
- Тарифы и промокоды.
- Настройки: Telegram-бот и группа, тест отправки, демо-режимы SMS и оплаты, контакты.

## Запуск

Нужен Node.js 18.17+.

```bash
npm install
cp .env.example .env   # заполните пароль админа, токен бота и ID группы
npm start              # http://localhost:3000, админка — /admin
```

Переменные `.env`: `PORT`, `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `DATA_DIR`.
Файл `.env` содержит секреты — не коммитьте его.

## Деплой
Любой VPS с Node.js: `npm ci --omit=dev && npm start` под pm2 или systemd, перед ним nginx с HTTPS.
Папку `data/` (или `DATA_DIR`) нужно бэкапить.

## Следующие шаги

- При росте нагрузки — перенести `server/db.js` на PostgreSQL.
