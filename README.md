# AI Master — демо платформы

Интерактивный прототип образовательной платформы по ИИ (по ТЗ проекта).
Одностраничный сайт: `index.html` (HTML + CSS + JS, без сборки).

## Что внутри
- Публичная часть: главная, каталог, страница курса, тест уровня, тарифы, для бизнеса, блог, проверка сертификата, юр. страницы
- Вход по телефону (демо-код 1234), онбординг
- Плеер урока: блоки (текст, схема, выноски, код, формулы, квизы), песочница с автопроверкой кодом, ИИ-наставник
- Кабинет студента, демо-оплата Click / Payme, кабинет компании, админ-панель
- UZ / RU / EN, тёмная тема

## Запуск
Открыть `index.html` в браузере. Данные хранятся в localStorage.
Песочница и наставник используют модель только внутри артефакта Claude (capability `sample`); вне его работают в демо-режиме.
