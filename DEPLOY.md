# Как выложить AI Master на сервер

Подходит любой VPS/VDS с **Ubuntu 22.04 или 24.04**, от 1 ГБ памяти и 10 ГБ диска.
Вся установка — один скрипт, примерно 10 минут.

## 1. Домен

В панели домена создайте DNS-записи (тип **A**) на IP-адрес сервера:

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | IP сервера |
| A | `www` | IP сервера |

Записи начинают работать через 5–30 минут, иногда дольше.

## 2. Загрузка файлов на сервер

На своём компьютере откройте PowerShell в папке с архивом и выполните (замените `IP` на адрес сервера):

```powershell
scp ai-master-*.zip root@IP:/root/
```

Затем подключитесь к серверу:

```powershell
ssh root@IP
```

На сервере распакуйте архив:

```bash
apt-get update && apt-get install -y unzip
mkdir -p /opt/aimaster && unzip -o /root/ai-master-*.zip -d /opt/aimaster
cd /opt/aimaster
```

## 3. Установка

```bash
bash deploy/setup.sh ваш-домен.uz ваша@почта.uz
```

Почта нужна только для уведомлений от Let's Encrypt о сертификате; её можно не указывать.

Скрипт сам:
- установит Node.js 20, pm2, nginx, certbot;
- добавит файл подкачки 1 ГБ;
- создаст `.env` с **новым паролем админки** и выведет его на экран — сохраните пароль;
- запустит сайт с автозапуском после перезагрузки;
- включит файрвол и HTTPS;
- настроит ежедневную копию данных в `/var/backups/aimaster` (14 дней).

## 4. Telegram

Откройте настройки и впишите токен бота и ID группы:

```bash
nano /opt/aimaster/.env
```

```
TELEGRAM_BOT_TOKEN=токен-вашего-бота
TELEGRAM_CHAT_ID=-5069810731
```

Сохраните (`Ctrl+O`, `Enter`, `Ctrl+X`) и перезапустите сайт:

```bash
pm2 restart aimaster --update-env
```

Проверьте отправку: **админка → Настройки → «Тестовое сообщение»**.

## 5. Проверка

- Сайт: `https://ваш-домен.uz`
- Админка: `https://ваш-домен.uz/admin` (логин `admin`, пароль — из шага 3)
- Оставьте тестовую заявку на сайте — она должна прийти в группу.

Если HTTPS не включился (домен ещё не указывал на сервер), подождите и повторите:

```bash
cd /opt/aimaster && bash deploy/setup.sh ваш-домен.uz
```

## Обновление сайта

Загрузите новый архив так же, как в шаге 2, распакуйте поверх и выполните:

```bash
cd /opt/aimaster && bash deploy/setup.sh ваш-домен.uz
```

Папки `data/` (заявки и статистика) и `.env` при этом не затрагиваются.

## Полезные команды

| Что | Команда |
|---|---|
| Статус сайта | `pm2 status` |
| Логи | `pm2 logs aimaster` |
| Перезапуск | `pm2 restart aimaster` |
| Резервные копии | `ls /var/backups/aimaster` |
| Восстановить копию | `tar -xzf /var/backups/aimaster/data-ДАТА.tar.gz -C /opt/aimaster && pm2 restart aimaster` |
